# [Sharif](https://en.sharif.edu) [MP](https://docs.ce.sharif.edu/course/40429) Organization

The MP (Mobile Programming) Organization is committed to providing a rich educational resource for students, educators, and enthusiasts in the field of Mobile Programming. Our repositories host a variety of resources, including study materials, coding exercises, and project examples of the course in the SUT (Sharif University of Technology).

## Featured Repository: [Materials](https://github.com/sut-mobile/Materials)

The `Materials` repository houses a comprehensive collection of educational materials for the Mobile Programming course in the SUT. It includes assignments, exams, lecture slides, and sources for both students and educators.
